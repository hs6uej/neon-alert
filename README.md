# NEON ALERT

เกม RTS สร้างฐานบนเว็บ แรงบันดาลใจจาก Red Alert 2 — ธีมนีออนล้ำยุค เล่นได้สูงสุด **3 คน** ถ้าไม่มีเพื่อนก็เล่นกับ **บอท** ได้
(A neon, isometric, base-building RTS for up to 3 commanders. Empty slots are filled by AI bots.)

**จุดเด่น:** สร้างฐาน + เก็บแร่ + สงครามแบบ RA2 · ยูนิตล้ำยุค 11 แบบ + อาวุธวินาศ Orbital Lance · เล่นกับบอท หรือออนไลน์สูงสุด 3 คน · ระบบบัญชี / matchmaking / เรตติ้ง Elo / ลีดเดอร์บอร์ด · แผนที่ 3 แบบ · เลือกสีผู้เล่น · ภาษาไทย/อังกฤษ · หน้า Admin แก้ค่าเกมได้ทั้งหมด · รันด้วย Docker ได้ · ไม่ต้องมีฐานข้อมูลและไม่มีไฟล์ภาพตั้งต้น (วาดด้วยโค้ดทั้งหมด — แอดมินเพิ่มรูปของตัวเองได้ผ่าน Picture studio)

## เริ่มเล่น

```bash
git clone https://github.com/hs6uej/neon-alert.git
cd neon-alert
npm install
npm start
```

ต้องใช้ Node.js 18 ขึ้นไป (ทดสอบบน Node 22/24)

แล้วเปิด http://localhost:3000 (บน Windows ดับเบิลคลิก `start.bat` ก็ได้)

| โหมด | วิธีเล่น |
| --- | --- |
| **Find match (ranked)** | เข้าคิวจับคู่กับผู้เล่นเรตติ้งใกล้กัน ไม่มีคนก็เติมบอทให้ (ดูหัวข้อ Matchmaking) |
| **Skirmish vs AI** | เล่นคนเดียวกับบอท 1–2 ตัว (ง่าย / ปกติ / ยาก) เลือกแผนที่และสีได้ — รัน simulation ในเบราว์เซอร์เอง |
| **Online lobby** | ต้อง **สมัคร/ล็อกอิน** ก่อน → เห็นรายการห้อง + แชทรวม กด *Create room* หรือ *Join* / พิมพ์โค้ด 4 ตัวอักษร ในห้องเลือก **แผนที่ สี ทีม** และประเภทช่องได้ ช่องที่ว่างจะถูกเติมด้วยบอทตอนเริ่ม ถ้าเพื่อนหลุดกลางเกม บอทจะเล่นแทน เพื่อนในวง Wi-Fi/LAN เดียวกันเปิด `http://<IP-เครื่องคุณ>:3000` (ล็อบบี้แสดง IP ให้) |

เล่นผ่านอินเทอร์เน็ต: เปิดพอร์ต 3000 หรือใช้ tunnel (เช่น `cloudflared tunnel --url http://localhost:3000` หรือ `ngrok http 3000`) แล้วส่งลิงก์ให้เพื่อน

## รันด้วย Docker

```bash
docker compose up -d --build
```

- คัดลอก `.env.example` เป็น `.env` ก่อน (`cp .env.example .env`) แล้วตั้งค่า `PORT`, `ADMIN_USER`, `ADMIN_PASS` (**เปลี่ยนรหัสผ่านตั้งต้น**), `TRUST_PROXY`, `MM_*`, `GEMINI_API_KEY` (ไม่บังคับ) — ไฟล์ `.env` ไม่ถูกเก็บใน git
- ข้อมูลผู้ใช้/เซสชัน/ค่า admin/ประวัติแมตช์/log เก็บใน volume `neon-alert-data` (ไม่หายเวลา rebuild) — ล้างทั้งหมดด้วย `docker compose down -v`
- บัญชี admin จาก `.env` ถูกสร้างครั้งแรกที่สตาร์ท **ถ้ายังไม่มีบัญชีนี้** เปลี่ยนรหัสใน `.env` ภายหลังไม่มีผลกับบัญชีเดิม → ใช้หน้า Admin › Users › Reset password
- `.env` อยู่ใน `.gitignore` (มี `.env.example` ให้แทน) อย่า commit รหัสผ่านจริงขึ้น repo

## ภาษา (ไทย / English) และแผนที่

- **เลือกภาษา** ด้วยปุ่ม `EN` / `ไทย` มุมขวาบนของเมนู (จำค่าไว้ในเบราว์เซอร์ เริ่มต้นตามภาษาของเบราว์เซอร์) และมีปุ่มเดียวกันในหน้า Admin — ระบบแปลเมนู HUD ชื่อยูนิต/อาคาร ข้อความจากเซิร์ฟเวอร์ และเสียงผู้ประกาศ (ถ้าเครื่องมีเสียงภาษาไทย ถ้าไม่มีจะพูดอังกฤษ) เพิ่ม/แก้คำแปลที่ `public/js/i18n.js` (ตัวแปร `GA.i18nMissing` ในคอนโซลบอกข้อความที่ยังไม่มีคำแปล)
- **แผนที่ 3 แบบ + สุ่ม** เลือกได้ตอน Skirmish และในห้องออนไลน์ (เจ้าของห้องเป็นคนเลือก, Find match สุ่มหนึ่งในสามแบบ) — แผนที่ที่ออกแบบไว้สมมาตร 3 ทาง ทุกฐานได้แร่เท่ากัน:
  - **Triad Crossing** สนามเปิด กำแพงหินมีประตูแบ่งฐาน ใจกลางมีกำแพงล้อมและแร่ทองคำ
  - **Sunken Isles** ฐานอยู่บนเกาะ เชื่อมด้วยสะพานดินแคบเหนือน้ำ — โดรนบินมีค่ามาก
  - **Iron Highlands** หน้าผาและหุบเขาคดเคี้ยว
  - **Wildlands** แผนที่สุ่มใหม่ทุกเกม (แบบเดิม)
  
  ตรวจความเชื่อมต่อ/ความยุติธรรมของแร่ได้ด้วย `node test/maps.js`

## Matchmaking, สถิติ และ log การเข้าสู่ระบบ

- **Find match (ranked)** ในเมนูหลัก: เข้าคิว → จับคู่ผู้เล่นที่เรตติ้งใกล้กัน (ช่วงที่รับได้เริ่ม ±150 และกว้างขึ้นเรื่อยๆ ตามเวลารอ) ครบ 3 คนเริ่มทันที, รอ `MM_PAIR_WAIT` วินาที (15) ได้ 2 คนก็เริ่มแบบ ranked, ถ้าอยู่คนเดียวรอ `MM_BOT_WAIT` วินาที (40) แล้วเติมบอท 2 ตัว (unranked) — ปิดการเติมบอทได้ที่ช่อง "Fill with AI"
- **เรตติ้ง (Elo)**: เริ่มที่ 1000, อันดับตามลำดับที่รอดจนท้าย (ผู้ชนะที่ 1) คิดแบบจับคู่ทุกคู่ (K=32) ออกจากเกมกลางคัน = อันดับสุดท้ายของมนุษย์ ผลแสดงที่หน้าจบเกม
- **หน้า Stats**: เรตติ้ง/อันดับ/เกม/อัตราชนะ/K-L/เวลาเล่น/win streak, ประวัติแมตช์ล่าสุด, **Leaderboard** Top 20 และ **ประวัติการเข้าสู่ระบบ** ของตัวเอง (รวมความพยายามล็อกอินที่ผิด) — Skirmish ออฟไลน์นับแยกเป็น "vs AI" ไม่กระทบเรตติ้ง
- **Log การเข้าสู่ระบบ** (Admin › *Sign-in logs*): บันทึกทุกเหตุการณ์ register / login / login ผิด / ถูกบล็อก (rate limit) / logout / เปิดซ้อนหลายหน้าต่าง รวมถึงการกระทำของ admin (รีเซ็ตรหัส, เปลี่ยนสิทธิ์, ลบผู้ใช้, บันทึก config, ปิดห้อง) พร้อม IP และ browser กรองได้ และ Export CSV — เก็บในไฟล์ `data/auth.log` (หมุนไฟล์ที่ 2MB) แมตช์ทั้งหมดอยู่ใน `data/matches.json` (ล่าสุด 500 แมตช์)
- อยู่หลัง reverse proxy/tunnel ให้ตั้ง `TRUST_PROXY=1` เพื่อให้ log เก็บ IP จริง (ถ้ารันผ่าน Docker Desktop ตรงๆ IP ของผู้เล่นจะเห็นเป็น IP ของ gateway)

## บัญชีผู้ใช้ & Admin

- บัญชี **แรก** ที่สมัครบนเซิร์ฟเวอร์จะเป็น **admin** อัตโนมัติ (หรือกำหนดล่วงหน้าด้วย env: `ADMIN_USER=xxx ADMIN_PASS=yyyyyy npm start`)
- รหัสผ่านเก็บแบบ salted scrypt ใน `data/users.json` (สร้างเอง ไม่ต้องมี DB) — เซสชันอยู่ 30 วัน
- **หน้า Admin** ที่ `/admin` (มีปุ่มในเมนูหลักเมื่อเป็น admin): แก้ค่าทุกอย่างที่เคยอยู่ใน `public/js/data.js` — ราคา/เวลาสร้าง/HP/ความเร็ว/พลังงาน/อาวุธ/ตารางความเสียหาย (Armor)/ความยากบอท/กติกาทั่วไป (เงินเริ่มต้น ความเร็วเก็บแร่ Orbital Lance ฯลฯ) พร้อมไฮไลต์ช่องที่ต่างจากค่าเริ่มต้น, จัดการผู้ใช้ (ตั้ง/ถอด admin, รีเซ็ตรหัส, รีเซ็ตสถิติ, ลบ), ดูแมตช์ ดู log และปิดห้อง
- **จัดการอาคาร/ยูนิต** (Admin → แท็บ **Structures / Units / Weapons**): ทุกการ์ดมี **รูป** ของอาคาร/ยูนิตที่เกมวาดจริง และสวิตช์ **In battle** — เอาเครื่องหมายถูกออก = ชนิดนั้น**ไม่ลงสนามรบ** (สร้าง/ฝึกไม่ได้ ไม่โผล่ในแถบสร้างและคู่มือ บอทข้ามให้ และอาคารเป็นกลางที่ปิดจะไม่ถูกวางบนแผนที่) ยกเว้น Nexus Core / Fusion Reactor / Ore Processor / Nano Harvester ที่เกมขาดไม่ได้ · กด **＋ New building / ＋ New unit** เพื่อ**สร้างอาคาร/ยูนิตใหม่เอง** เป็นสำเนาของชนิดเดิม (หน้าตาและความสามารถตามต้นแบบ: สำเนาค่ายทหารฝึกทหารได้ สำเนาโรงกลั่นแร่กลั่นแร่และให้รถเก็บแร่ฟรี สำเนาเรดาร์เปิดมินิแมพ ฯลฯ) แล้วตั้งชื่อ ราคา HP ความเร็ว พลังงาน อาวุธ และสิ่งที่ต้องมีก่อนเอง · **＋ New weapon** สร้างอาวุธใหม่จากอาวุธเดิมแล้วเลือกให้ยูนิตใช้ได้ · ชนิดที่สร้างเองมีเครื่องหมายเพชรทองในเกมและบนไอคอน (สูงสุด 24 อาคาร/ยูนิต และ 12 อาวุธ) — เก็บรวมใน `data/config.json` และส่งให้ผู้เล่นทุกคนพร้อมกฎอื่นตอนเริ่มเกม (บอทไม่สร้างชนิดที่สร้างเอง)
- **ตัวแก้ไขแผนที่** (Admin → แท็บ **Maps**): วาดสนามรบสำหรับ 3 ผู้เล่นบนกริด 96×96 — พื้นโล่ง/กำแพงหิน/น้ำ, แร่ (น้อย/ปกติ/มาก), จุดเริ่มต้น 3 จุด (เปิดพื้นที่โล่งรอบจุดให้อัตโนมัติ), Crystal Derrick / Supply Depot, แปรงหลายขนาด/รูปทรง, เทสีทั้งบริเวณ, **โหมดสมมาตร** (หมุน ×3 ฐาน / กระจกซ้าย-ขวา / บน-ล่าง), Undo/Redo (Ctrl+Z / Ctrl+Y), โหลดเทมเพลตจาก 3 แผนที่ที่มีอยู่หรือ Wildlands ตามค่าสุ่มที่ต้องการ และแผงตรวจสอบสด (จุดเริ่มต้นเดินถึงกันไหม แร่เข้าถึงได้ไหม อาคารเป็นกลางวางถูกที่ไหม) — บันทึกแล้วจะเก็บใน `data/maps.json` และขึ้นในตัวเลือกแผนที่ของโหมดเล่นกับบอทและห้องออนไลน์ให้ทุกคนทันที (สูงสุด 24 แผนที่, ขอบแผนที่ทำลายไม่ได้เสมอ)
- **รูปของอาคาร/ยูนิต (Picture studio)**: ทุกการ์ดมีปุ่ม **🎨 Draw** เปิดหน้าต่างสร้างรูปใหม่ได้ 3 ทาง — (1) **ให้ AI (Google Gemini) วาด** จากคำบรรยาย เลือกสไตล์ได้ และติ๊ก "Start from what is on the canvas" เพื่อให้ AI ปรับต่อจากภาพ/ภาพร่างที่มีอยู่ (2) **อัปโหลดไฟล์** PNG/JPG (3) **วาดเอง** ด้วยปากกา/ยางลบ + Undo — ระบบตัดพื้นหลังสีเรียบออกให้อัตโนมัติ (ปรับความแรงได้) ครอบภาพพอดีตัว ย่อขนาด และมีพรีวิวว่าจะเห็นอย่างไรในเกม (ปรับขนาด/ตำแหน่งขึ้นลง เห็นเส้นขอบพื้นที่วาง) เมื่อกด **Use this picture** แล้วกด **Save changes** รูปจะถูกใช้ในเกม แถบสร้าง และคู่มือ (ยูนิตจะกลับซ้าย/ขวาตามทิศเดิน มีวงสีทีมใต้ตัว อาคารมีแผ่นฐานสีทีม) · ตั้ง `GEMINI_API_KEY` (และถ้าต้องการ `GEMINI_IMAGE_MODEL`, ค่าเริ่มต้น `gemini-2.5-flash-image` — ต้องเป็นโมเดลที่ *ออกรูปได้*) ใน `.env` แล้วรีสตาร์ท ถ้าไม่ตั้ง ปุ่ม AI จะปิดแต่อัปโหลด/วาดเองยังใช้ได้ · key อยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ไฟล์รูปเก็บที่ `data/art/` (PNG ≤ 600 KB) ชนิดที่สร้างเองใช้รูปของต้นแบบจนกว่าจะวาดรูปของตัวเอง · ชนิดที่ไม่มีรูปยังใช้ภาพวาดด้วยโค้ดเดิม
- ค่าที่แก้เก็บเป็น *overrides* ใน `data/config.json` (ไม่แก้ไฟล์ data.js) กด Reset ได้ทุกเมื่อ ค่าใหม่ใช้กับ **เกมที่เริ่มใหม่** — ถ้ามีเกมออนไลน์กำลังเล่นอยู่ ระบบจะรอให้จบก่อนแล้วค่อยใช้
- ใช้กับอินเทอร์เน็ตจริง: ควรวางหลัง HTTPS (เช่น cloudflared/ngrok/reverse proxy) เพราะรหัสผ่านวิ่งผ่านเครือข่าย

## วิธีเล่น

1. สร้าง **Fusion Reactor** (ไฟฟ้า) → **Ore Processor** (มี Nano Harvester ให้ฟรี ขุดคริสตัลสีเขียวอัตโนมัติ)
2. คลิกการ์ดในแถบขวา รอจนขึ้น **READY** แล้วคลิกอีกครั้ง เพื่อวางอาคารใกล้ฐาน
3. **Barracks** ผลิตทหารราบ, **Assembly Forge** ผลิตยานพาหนะ/โดรน, **Sensor Array** = มินิแมพ + ยูนิตขั้นสูง, **Quantum Lab** = เทคสูงสุด + **Orbital Uplink** (อาวุธวินาศ Orbital Lance)
4. ไฟฟ้าไม่พอ = ผลิตช้าลง, ป้อมและเรดาร์ดับ

**สิ่งที่ทำลาย/ยึดได้ในแผนที่**
- **กำแพงหิน** ภายในแผนที่ทำลายได้ (หินขอบแผนที่ทำลายไม่ได้): คลิกขวาที่หินด้วยยูนิตติดอาวุธ (หรือกด `A` แล้วคลิกหิน) เพื่อระดมยิงจนพังเป็นทางเดิน กระสุนระเบิดวงจะเจาะหินรอบข้างช้าๆ และ Orbital Lance เจาะเป็นหลุมใหญ่ (HP หิน / สัดส่วนสเปลชปตั้งได้ในหน้า Admin → Rules)
- **อาคารเป็นกลาง** วางระหว่างฐานทุกแผนที่: **Crystal Derrick** (ยึดแล้วได้เงินต่อเนื่อง) และ **Supply Depot** (ยึดแล้วได้โบนัสเงินครั้งเดียว) ยึดด้วย Breach Engineer หรือยิงทำลายได้ ยูนิตจะไม่ยิงอาคารเหล่านี้เองอัตโนมัติ ต้องสั่งโจมตีเท่านั้น

ยูนิต: Pulse Trooper, Rocket Lancer (ยิงอากาศได้), Breach Engineer (ยึดอาคารศัตรู), Nano Harvester, Vector Hover, Arc Tank, Nova Mortar (ปืนใหญ่ระยะไกล), Wasp Drone (บิน), Rail Striker (ปืนราง), Titan Walker, Mobile Nexus (MCV — กด `D` เพื่อตั้งฐานใหม่)

| `A` | Attack-move · `S` หยุด · `D` Deploy MCV · `H` กลับฐาน · `Space` ไปจุดที่ถูกโจมตีล่าสุด |
| `Ctrl+1..9` / `1..9` | ตั้ง / เรียกกลุ่ม (กดซ้ำ = โฟกัสกล้อง) |
| `R` / `X` | โหมดซ่อม / ขาย อาคาร |
| `Tab` | สลับแท็บสร้าง · `Shift+คลิก` การ์ด = ต่อคิว 5 ชิ้น |
| ลูกศร / ขอบจอ / ลากปุ่มกลาง / ล้อเมาส์ | เลื่อนกล้อง / ซูม |
| `Enter` | แชท (ออนไลน์) · `Esc` เมนู/ยกเลิก |

**เล่นบน iPad / จอสัมผัส** (เปิดโหมดสัมผัสอัตโนมัติ): **แตะ** ยูนิตเพื่อเลือก · เมื่อเลือกยูนิตแล้ว **แตะพื้น** = เดิน, **แตะศัตรู/อาคารกลาง/หิน** = โจมตี/ยึด · **ลาก**แผนที่หรือกด **แผ่นเลื่อนใหญ่ตามขอบจอ** ค้างไว้ = เลื่อนกล้อง · **ถ่างนิ้ว** = ซูม · **กดค้าง**ที่พื้น = เคลื่อนที่-โจมตี (กดค้างที่ยูนิต = เลือกชนิดเดียวกันทั้งจอ) · ปุ่ม **Select** = ลากกรอบเลือกหลายยูนิต · ปุ่ม Attack / Stop / Base / Clear ที่ขอบซ้าย · ตอนวางอาคารให้ลากเพื่อเล็งแล้วกด **Build here** (ยิงอาวุธวินาศ: กด **Fire here**)

แถบสร้างด้านขวาแสดง**เฉพาะสิ่งที่สร้างได้ในตอนนั้น** (ของที่ยังขาดอาคารต้นทางจะซ่อน และแท็บที่ว่างจะซ่อนไปด้วย)

## โครงสร้างโปรเจกต์

```
server.js            HTTP + WebSocket, บัญชี, ห้อง/ล็อบบี้/matchmaking, simulation แบบ authoritative (20 Hz)
public/js/data.js    ค่าเริ่มต้นของยูนิต/อาคาร/อาวุธ/กติกา/รายชื่อแผนที่ (ใช้ร่วมทั้ง server และ browser)
public/js/config.js  ระบบ override ค่าจากหน้า admin (validate + apply)
public/js/mapdata.js  รูปแบบ/การตรวจสอบ/ทะเบียนแผนที่ที่แอดมินสร้าง (ใช้ร่วม server, เกม และ admin)
public/js/mapeditor.js ตัวแก้ไขแผนที่ในหน้า Admin
public/js/artstudio.js หน้าต่างวาดรูปอาคาร/ยูนิต (AI / อัปโหลด / วาดเอง) ในหน้า Admin
public/js/i18n.js    พจนานุกรมไทย/อังกฤษ + ตัวแปลอัตโนมัติ
public/admin.html    หน้า Admin (+ js/admin.js)
data/                users.json, sessions.json, config.json, matches.json, auth.log, art/ (รูปอาคาร/ยูนิต) (สร้างอัตโนมัติ)
public/js/sim.js     ตัวเกม: แผนที่ (4 แบบ), pathfinding (A*), การรบ, เศรษฐกิจ, fog-of-war snapshot
public/js/ai.js      บอท (ใช้ command API เดียวกับผู้เล่น)
public/js/render.js  วาด isometric แบบ procedural (ไม่มีไฟล์ภาพ)
public/js/game.js    สถานะฝั่ง client, interpolation, เอฟเฟกต์, input
public/js/ui.js      HUD / แถบสร้าง / แผงเลือก      public/js/audio.js  เสียงสังเคราะห์ + ผู้ประกาศ
test/                headless.js (บอทสู้กัน), features.js, maps.js (แผนที่), net-test.js (สมัคร/ล็อกอิน/admin/log/ล็อบบี้/สี/แผนที่/matchmaking/Elo — เปิดเซิร์ฟเวอร์ชั่วคราวเอง)
```

Tests: `npm test` (บอทล้วน), `node test/features.js`, `node test/maps.js`, `node test/net-test.js`
